How the discrete PID works

u[k] = Kp·e[k] + Ki·Ts·Σ(j=0…k)e[j] + Kd·(e[k] − e[k−1])/Ts

At t = kTs the controller reads the output and computes e[k] = r − y[k]. The first derivative term is zero. The actuator clamps the command to [0, umax] and holds it until the next sample. The plant still advances with 1 ms RK4 steps between samples.

Anti-windup skips adding an error when the raw command is beyond a limit and the error pushes it farther into that limit. An error that drives the command back toward range can still update the sum.
